# 研报写作规范（分析逻辑 + 文字）

目标：读起来像卖方分析师写的年报点评，而不是程序运行记录。核心是**把会计指标的变化回溯到业务场景**，
再落到盈利预测和投资建议上。数字规则不变（全部来自运行产物、正文过 `guard`）。

## 一、分析链条：会计指标 → 业务驱动 → 预测假设 → 估值 → 投资建议

每写一个指标，先问“这个数是业务上哪件事造成的”，再问“这件事明年还会不会继续”。

| 会计指标 | 回溯到的业务问题（先查经营数据 extras，再查管理层讨论） | 落到哪个预测假设 |
|---|---|---|
| 营业收入 | 量（销量、基酒产能与投放）× 价（出厂价、批价、吨价）× 结构（产品、渠道、地区） | 分部销量增速、吨价增速 |
| 毛利率 | 产品结构（高毛利产品占比）、渠道结构、成本（原料、包材、人工） | 分部毛利率变动 |
| 销售费用率 | 市场投入、渠道改革、新品推广；投入是否换来量 | 销售费用率路径 |
| 管理费用率 | 人员与薪酬、规模效应 | 管理费用率 |
| 合同负债 / 预收 | 经销商打款意愿、渠道库存与批价预期（先行指标） | 下一年收入节奏的佐证 |
| 存货 | 基酒储备（白酒）/ 产成品积压（一般消费品）要区分 | 营运资本天数 |
| 经营现金流 | 回款质量；金融子公司等非主业口径扰动要剥离 | 现金流预测口径 |
| 分红 / 回购 | 股东回报政策与现金储备 | 分红率假设、股本 |

行业不同，驱动换成对应的：制造业看产能利用率、订单与价格、原材料；消费品看量价、渠道库存、动销；
周期品看价格与开工率。经营数据表（extras）要覆盖这些驱动，预测模型（segment_forecast）用同一套驱动。

**前后必须对应**：经营分析里写到的每一个变化（如系列酒降价、直销占比提升、销售费用加大），
都要在盈利预测假设里找到对应的参数，并在假设表里写明依据。

## 二、段落写法

- **结论先行**：小标题和段首句就是结论（“系列酒量增价减，拖累收入”），后面跟数据，再跟业务原因，最后是影响判断。
- **事实、推论、观点用措辞区分**，不用彩色标签：事实直接陈述数据；推论写“主要系……”“反映……”；
  观点和预测写“我们认为”“我们预计”。附录用一段“内容说明”交代三层口径。
- **因果写业务**：写“直销渠道放量叠加产品结构调整，直销吨价下降”，不写“直销吨价由 A 降至 B，说明产品组合变化”。
- **一个段落一个意思**，避免把五个数字串成一句。数字不必全写，挑支撑结论的。
- 正文**不引用页码和资料位置**（“年报第 9 页说明”）；需要时写“公司披露”“据年报”，来源统一放在图表下方。

## 三、句式黑名单

| 句式 | 处理 |
|---|---|
| “与年报……的解释一致”“与……方向一致” | 删除。直接写业务原因 |
| “是……而不是……”“并非……而是……” | 少用，每篇至多一两处；改成正面陈述 |
| “年报第 N 页说明……” | 删除页码，改“公司披露……主要系……” |
| “（观点）”“【事实】”等行内标签 | 删除，靠“我们认为/预计”区分 |
| “需要说明”“值得注意的是” | 删除，直接写内容 |
| “这是公司多年来首次……”等无出处的判断 | 删除，除非产物里有数据支撑 |

## 四、自证类语句：改成正规备注还是直接删除

程序为自洽加的说明，读者不需要在正文里看到。按下表处理：

| 原句类型 | 处理 | 放到哪里 |
|---|---|---|
| 估值假设为草稿、待确认 | 删除（这是给用户的交付说明，不进研报） | 交付时告诉用户 |
| 参考股价为外部行情数据、收盘日期 | 改为备注 | 基本数据表下“股价日期：……收盘” |
| 终值占比高、结论对 WACC 敏感 | 改为正常分析 | 估值章节的敏感性分析 |
| 口径简化（EBIT 含财务公司利息、少数股东占比不变、EPS 按期末股本） | 改为备注 | 附录“估值方法说明” |
| 预测参数取基年实际值 | 改为表注 | 假设表下方 |
| 数据抽取、逐字核对、数字护栏等方法描述 | 改为备注 | 附录“数据来源与方法” |
| “不构成投资建议” | 只保留一处 | 页脚与免责声明 |
| “不提供投资评级” | 删除；按评级规则给出评级 | 首页评级 + 附录“投资评级说明” |
| 图表配色说明（深色为实际、浅色为预测） | 改为图例 | 图内图例 |
| “以上为筛选级测算” | 删除 | — |

## 五、投资建议板块（首页必备）

“● 盈利预测及投资建议”一段：先一句核心逻辑（为什么看好/谨慎），再给预测（未来三年收入、归母净利润、EPS 及增速），
再给估值（当前股价对应 P/E、DCF 每股价值），最后给评级。评级由程序按 `forecast_summary.rating` 的规则给出，
正文只引用，不自己定；附录“投资评级说明”写明规则。

## 六、学习优秀研报

`references/exemplars/` 放用户提供的优秀研报（PDF）。写作前先读 2～3 篇同行业的，按下表总结后追加到本文件末尾“学习记录”：
每篇的结构（章节顺序、首页要素）、分析链条（从哪个会计指标回溯到哪个业务场景）、常用句式、图表清单。
只总结方法，不摘抄原文。
