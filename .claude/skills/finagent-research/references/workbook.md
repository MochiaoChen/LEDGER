# Excel 工作簿排版规范（model.xlsx / comps_formula_workbook.xlsx）

目标：交出去的工作簿要达到卖方研究（高盛、中金等）模型的观感：干净、一眼能分清输入与公式、数字格式统一、打印不乱。
排版由程序统一实现（`finagent/output/xlsx.py` 的 `Sheet` / `Cell` / `Formula`），**不要手工改产物**；
新增或修改工作表时按本规范写排版参数，并在 Excel 里打开复核。

## 一、视觉

| 项目 | 规范 |
|---|---|
| 字体 | 中西文配对：**Arial 配楷体（KaiTi，默认）**，Times New Roman 配宋体（SimSun），不混搭；正文 10 号，页首标题 14 号加粗深蓝。数值单元格用西文字体；文字单元格写成富文本，中文字符（含全角标点）用中文字体、字母数字用西文字体；公式返回的中文（如引用的公司名）整格用中文字体。不要用工作簿主题指定中文字体：中文界面的 Excel for Mac 会把主题中文字体当正文字体，连数字都变成楷体 |
| 表头 | 深蓝底（`1F3864`）白字加粗、居中，下边中粗线；文字超出列宽时两行高，否则单行 |
| 正文 | 白底，行间浅灰细线（`BFBFBF` hair）；行高 16 磅 |
| 合计行 | 加粗，上边黑色细线（NOPAT、FCFF、企业价值、股权价值、毛利、净利润、资产总计等） |
| 小节标题 | 浅蓝底（`DCE6F1`）加粗，铺满全表宽 |
| 关键输出 | 浅黄底（`FFF2CC`）：基准情景、每股价值、敏感性表的基准格、目标公司行、WACC |
| 网格线 | 关闭；冻结表头行与首列；缩放 90% |
| 打印 | A4 横向、按页宽缩放、页边距 0.5 英寸 |
| 列宽 | 按内容自动估算（中文按 2 个字符宽），标签列 22～34，长说明列 60～110 并自动换行 |

## 二、颜色代表来源（不可混用）

| 颜色 | 含义 |
|---|---|
| 蓝色 `0000FF` | 硬编码输入：财报抽取值、三表模型输出、估值假设、同业数据 |
| 黑色 | 公式 |
| 绿色 `008000` | 纯跨表引用（如 `=WACC!$B$19`、`=同业数据!B3`） |

## 三、数字格式

| 类型 | 格式 | 示例 |
|---|---|---|
| 金额（百万元） | `#,##0.0_);(#,##0.0);"-"_)` | 5,862.3 / (303.3) / - |
| 大额（EV、股权价值列表） | `#,##0_);(#,##0);"-"_)` | 9,990 |
| 每股（元）、股价 | `#,##0.00_);(#,##0.00);"-"_)` | 11.67 |
| 比率 | `0.0%`（WACC、成本类 `0.00%`），负数括号 | 12.6% / (8.9%) |
| 倍数 | `0.0"x"` | 7.5x |
| 变动（敏感性轴） | `+0.0%;-0.0%;0.0%`、`+0.0"x"` | +1.0% |
| 百分点差 | `+0.0" pp"` | -3.0 pp |
| 百分点差（照录年报原文） | `+0.00" pp"` | -0.53 pp |
| 折现系数 | `0.0000` | 0.9613 |

- 负数一律括号，零显示“-”；比率存小数（0.126 显示 12.6%），不要存 12.6。
- 单位写在表头或行标签里：“营业收入（百万元）”“每股价值（元）”，不要在单元格里写单位文字。
- 年份/期间写成文字：`FY2024A`（实际）、`FY2025E`（预测）。

## 四、结构

- **期间横排**：DCF、三表页期间在列、科目在行；实际列（后缀 `A`）在前，预测列（后缀 `E`）在后。
- **每页页首**：第 1 行标题（公司 + 表名 + 情景），第 2 行灰色斜体单位与颜色说明，第 3 行空，第 4 行起表头。
- **能用公式的地方写公式**，缓存值填引擎结果（打开即显示、改输入即重算）：NOPAT、FCFF、折现系数、现值、
  终值、企业价值、股权桥、每股价值、WACC 构成、comps 的倍数/统计/隐含股价/利润率。
- 公式按固定行列引用，**加排版不能挪动行列**；要加行，先改公式引用。
- 敏感性表：行轴、列轴用绝对值（WACC 8.21%、永续增长 2.00%、退出倍数 10.0x），利润率与增速用相对变动；
  行轴加粗浅蓝底，基准格浅黄。
- 目标公司放第一行并高亮；同业分 Core / Secondary / Excluded，剔除理由写在来源台账。

## 五、model.xlsx 工作表顺序

估值汇总 → 盈利预测 → DCF → WACC → 敏感性 → 非经营性资产（有明细时） → 三表-利润表 / 资产负债表 / 现金流量表（含实际年度列） → 历史财务 → 分季度 → 经营数据（有补充表格时） → 可比公司 → 模型检查

## 六、交付前自查

1. 在 Excel 中打开（公式工作簿会打开即重算），逐页看：无 `#DIV/0!`、`#NAME?`、`#VALUE!`，无“####”（列宽不足）。
2. 关键公式结果与引擎一致：DCF 页企业价值、股权价值、每股价值 = `valuation/valuation.json`；
   comps 隐含股价区间 = `valuation/comps.json`（`tests/test_golden.py`、`tests/test_quarterly_ebit.py` 已自动核对缓存值）。
3. 颜色与来源一致：没有蓝色的公式、没有黑色的硬编码数字。
4. 字体：放大看，数字和英文是 Arial，中文是楷体。
5. 横向打印预览一页宽内放得下。

## 七、三表联动页（三表-假设 / 利润表 / 资产负债表 / 现金流量表）

计算仍由引擎完成，工作簿把同一套逻辑写成公式，打开即显示引擎结果、重算结果相同（引擎功能超出公式覆盖范围时退回数值表）：

- **三表-假设**：B5 情景开关（1 悲观 / 2 基准 / 3 乐观），情景相关驱动（收入增速、毛利率、应收天数、资本开支率、
  永续增长率、WACC 调整）列三行输入 + 一行 `CHOOSE` 选用；其余驱动单行输入；实际年度列用公式反算历史比率。
  下方为辅助计算：营运资本、固定资产滚动、有息负债与利息、现金分红。
- **利润表**：预测期收入 = 上年 ×（1 + 增速），成本、费用、折旧、利息、所得税全部引用假设页；实际年度用
  “经营性税前利润 + 投资收益与公允价值变动 = 利润总额”对齐报表。
- **资产负债表**：货币资金取现金流量表期末现金，营运资本、PP&E、有息负债取辅助计算，留存收益 = 上年 + 净利润 − 分红；
  底部勾稽检查（资产 = 负债 + 权益、现金、留存收益、PP&E、有息负债滚动）为 `ROUND` 公式，结论单元格显示“全部平衡”。
- **现金流量表**：净利润、折旧取利润表，营运资本、资本开支、还款、分红取假设页；实际年度“其他经营项目”为轧差。
- **DCF / 盈利预测**：预测期收入、EBIT、折旧、资本开支、营运资本增加、净利润全部跨表引用三表页；WACC = 基准 + 情景调整。
- 交付前在 Excel 中切换 B5 为 1、3，核对 DCF 每股价值与 `valuation.json` 各情景一致，勾稽结论保持“全部平衡”。
