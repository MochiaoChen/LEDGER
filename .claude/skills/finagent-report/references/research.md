# 外部调研：联网检索与登记

年报只讲公司自己。行业有多大、增长多快、公司排第几、竞争对手怎么样、产品价格怎么走、年报披露之后发生了什么，
这些都要**现查**。你记忆里的行业数据可能过时、记错，甚至是编造的；即使很确定，也要先检索，查到并登记之后才能写。
检索不到的不写。

## 一、先列问题，再检索

在 framework.md 里写 `## 外部调研清单`：从投资主线和驱动清单倒推，列出 6～12 个**年报回答不了、但影响结论**的问题。
每个问题写清楚要什么数据、为什么要。常见类型：

| 类型 | 例 |
|---|---|
| 行业需求与规模 | 下游资本开支、行业市场规模与增速、渗透率 |
| 供给与价格 | 行业产能与新增供给、产品价格或运价指数、原材料价格 |
| 竞争格局 | 全球/国内排名与份额、主要竞争对手的规模与动作 |
| 公司近况 | 年报披露日之后的公告（订单、产能、分红、股权变动）、最新季报 |
| 政策与监管 | 行业政策、关税、出口管制、集采 |
| 估值参照 | 可比公司、行业估值区间（不提供 `--peers` 时只作文字参照） |
| 行情 | 未提供股价时，最近一个交易日收盘价 |

## 二、检索

- 每个问题至少检索一次，换两三个关键词（中英文都试）；WebSearch 找到候选后，用 WebFetch 打开原文核对数字。
  只看搜索结果摘要就登记，等于没核对。
- 来源优先级：交易所与公司公告 > 政府、统计局、行业协会 > 知名研究机构与行业数据商（如 Clarksons、TrendForce、
  Lightcounting、IEA）> 主流财经媒体。自媒体、论坛、百科、来源不明的转载不用。
- 注意时效：优先年报所属年度及之后发布的资料，写清发布日期；预测类数据写明是谁在什么时候做的预测。
- 只登记网页原文里出现的数字，**不要自己换算**（百分比、单位、币种都照原文）。
- 查不到就标 `not_found`，并在 framework.md 里把相关分析改成情景处理或删掉；如果它影响核心结论，写进 review.md。

## 三、登记 research/sources.json

```json
{
  "questions": [
    {"id": "Q1", "question": "2026 年全球油轮运力增速", "status": "found",
     "queries": ["2026 tanker fleet growth forecast", "2026 油轮 运力 增速"], "sources": ["S1"]},
    {"id": "Q2", "question": "公司 VLCC 船队全球排名", "status": "not_found",
     "queries": ["招商轮船 VLCC 船队 全球 排名"], "sources": []}
  ],
  "sources": [
    {"id": "S1", "title": "<网页标题>", "publisher": "<发布方>", "url": "https://...",
     "published": "2026-01-15", "accessed": "2026-10-02",
     "facts": [{"quote": "<原文中包含该数字的一句话，≤120 字>", "value": 2.1, "unit": "%",
                "label": "2026 年全球油轮运力增速（预测）"}]}
  ]
}
```

- `quote` 摘自原文、包含 `value` 的原样写法；`verify-sources` 会检查数字是否出现在摘句里。
- 定性判断（排名、“龙头”、政策内容）也登记成 fact，`value` 可省略，`quote` 写原文。
- 检查：`PY -m finagent verify-sources --sources <work>/research/sources.json`，到 `ok: true`。
  流水线闸门还要求至少 6 个问题、12 次检索。

## 四、怎么用

- 正文引用外部内容时句末加 `[S编号]`；guard 会把 sources.json 里的数字当作出处，但要求句子带对应编号，
  “龙头”“领先”“市场份额”之类的判断没有编号也会被拦下。
- 外部数据画图时，数值从 sources.json 读，`doc.fig(..., src="<发布方> [S编号]，FinAgent 整理")`。
- 估值假设可以引用外部调研（如运价预测、行业增速），在假设的依据里写 `[S编号]`。
- 附录“外部资料来源”由 reportkit 从 sources.json 自动生成。
