# 常见章节、可选图表与所需数据

这是菜单，不是清单。分析什么由 framework.md 决定，这里只列报告里常见的章节和 reportkit 现成的图表。按公司主线挑选、合并、改名；标题写结论（“直销占比过半，自营体系成为增量来源”），不写“渠道分析”。
“标准”指 reportkit 直接读运行产物即可生成；“extras”指要先把年报表格抄进 `extras.json`。

## 首页与目录（固定）

首页由 `layout.cover` 生成：标题、投资要点（`summary`）、评级与估值、基本数据（`Config.side_rows` 追加）、
收入利润小图、盈利预测表。目录与图表目录自动生成。首页要一页放完，投资要点宁短勿挤。

## 1 投资逻辑

- 文字：3～4 条核心观点 + “市场关注的问题与我们的判断”。
- 图：`C.history`（上上年到预测末年的收入与利润，标准）。
- 这一节决定全文结构：后面每一节都应能回答某条核心观点。

## 2 公司概况 / 行业

- 文字：业务模式与产品、客户与渠道、股权与治理、近三年经营轨迹、行业环境。
- 图表：`T.three_year`、`C.quality`（标准）；收入结构环形图 `C.donuts`、股东 `C.hbars`、员工构成 `C.hbars`（extras）。
- 行业部分用年报里公司自己的表述，加上外部调研登记的数据（句末 `[S编号]`，图注 `src=` 写发布方）。
  不凭记忆写行业数据、排名和事件。
- 非数据图表（讲故事用）：发展历程 `C.timeline`、产业链或业务模式 `C.flow`、同行定性对比与产品矩阵 `T.text_table`。

## 3 业绩回顾

- 文字：全年（收入、利润、扣非、利润质量）+ 分季度节奏。
- 图表：`T.core`、`C.quarterly`、`T.quarterly`（标准；环比、占全年比例用 extras 比率追加行）。

## 4～5 经营分析（核心，通常 2～3 节）

按 framework.md 的驱动清单拆（见 analysis.md），章节名和数量由公司决定。现成图形与适用场景：

| 分析 | 图 | 数据 |
|---|---|---|
| 分产品 / 分部收入与毛利率 | `C.panels`（收入与同比｜毛利率与变动）、`C.grouped` | 主营业务分产品表 |
| 量价拆分 | `C.grouped`（单价 vs 单位成本）、量价表 | 产销量表；单价、单位成本写成比率 |
| 产销存、产能 | `C.grouped`（产量 vs 销量，标同比）、`C.progress`（在建项目进度） | 产销量、产能、在建工程表 |
| 渠道 / 客户结构 | `C.stacked`（两期结构，柱顶标占比） | 分销售模式、前五大客户 |
| 区域 | 区域表、`C.grouped` | 分地区表 |
| 子公司 | `C.grouped`（收入与净利润，标净利率） | 主要控股参股公司表 |

## 6 盈利能力

- 文字：毛利率（结构 → 成本）、费用（明细 → 原因 → 可持续性）、利润归因。
- 图表：`C.bridge`（标准）；成本构成、采购、费用明细 `C.grouped`，费用率对比 `C.grouped`（extras）。

## 7 资产负债与现金流

- 文字：资产结构、营运资本与先行指标（合同负债、存货、应收）、经营现金流与净利润的差异来源、资本开支。
- 图表：`T.balance`、`C.cash_quarterly`（标准）；资产占比 `C.grouped`、存货构成 `C.stacked`、三类现金流 `C.signed`（extras）。

## 8 股东回报（可选）

- 分红、回购、分红率；`C.composition`（分红构成）、每股派息 `C.grouped`。

## 9 盈利预测

- 文字：关键假设逐条对应前文分析，再给结果。
- 图表：`T.assumptions(run, BASIS)`、`T.segment_forecast`、`C.segment_forecast`、`C.margins`、`T.forecast`（标准，需分部预测）。

## 10 估值

- 图表：`T.wacc`、`T.fcff`、`C.ev_bridge`、`T.scenario_table`、`C.scenarios`（标准，后两个需分部预测）；
  `layout.valuation_ranges(doc)` 一次生成估值区间图、全部敏感性矩阵和（有 `--peers` 时）可比公司表。
- 文字：参数依据、企业价值到每股价值、情景含义、终值占比与敏感性。

## 11～12 投资建议、风险提示

- 投资建议：核心逻辑 → 预测 → 估值 → 程序评级。
- 风险：与假设一一对应，能量化的引用悲观情景每股价值。

## 非数据图表

优秀研报约一半的图表不是财务数据图，它们负责把故事讲清楚。素材来自年报文字或外部调研，图注写明来源。

| 图 | 原语 | 适用 |
|---|---|---|
| 发展历程 / 产品推出时间轴 | `C.timeline(out, name, [(时间, 事件, 一句说明)])` | 公司概况、产品线演进 |
| 产业链 / 业务模式 / 收入驱动链 | `C.flow(out, name, [(环节, [要点])], highlight=公司所在环节)` | 行业与商业模式、“需求 → 量价 → 收入”推导 |
| 定性对比表 | `T.text_table(表头, 行)`，单元格可带 `[S编号]` | 与国内外同行对比品牌、稀缺性、技术路线；产品矩阵；管理层履历；政策梳理 |
| 外部数据图 | `C.grouped` / `C.stacked` 等原语 + `doc.fig(..., src="<发布方> [S编号]")` | 行业规模、价格指数、竞争对手规模对比 |

## 附录（固定）

`layout.appendix`：财务报表预测、非经营性资产明细、估值方法说明（`Config.method_note` 写公司特有口径）、
数据来源与方法、外部资料来源（有 `research/sources.json` 时自动生成）、内容说明、投资评级说明、免责声明。
