# DeepSeek-V4.1-Flash 双公司试跑

这是 2025 年年报的**原始模型对照稿**，不是已审核研报，也不是投资建议。宁德时代（300750）和招商轮船（601872）各保留分析框架、Markdown 初稿、自动检查结果与运行元数据，供负责人比较模型表现。年报原件在 `report/resources/`，本目录不重复存放 PDF 或提取的全文。

运行方式见仓库根目录 `README.md`。模型为 DeepSeek 官方 API 的 `deepseek-flash`，开启 thinking 且 reasoning effort 为 high；每家公司先生成 JSON 分析框架，再生成报告。`manifest.json` 记录年报 SHA-256、页码、请求哈希、耗时与 token 用量，**不含 API Key**。本次初稿没有输入可靠行情、估值假设，因此没有给出股价、目标价或评级。

## 自动检查与人工复核

自动程序仅验证引用的 PDF 物理页码是否在输入页集合中、带数字的段落是否有页码，以及是否出现明显编辑占位符。它**不能证明引用页支持该句结论**，也不能验证算术、财务口径、前瞻推断或文字质量。因此两份稿件均须人工逐条核对后方可正式使用。
