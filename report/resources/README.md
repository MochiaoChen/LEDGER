## 使用方式

以贵州茅台为例，先运行关键页定位：

```bash
python -m finagent locate --input report/resources/贵州茅台/600519_贵州茅台_2025_年度报告.pdf
```

再把同一路径作为主流程的 `--input`。其余两家公司只需替换路径。年报本身已包含经审计财务报表及附注，因此没有重复保存单独审计报告；ESG 报告也不属于当前财务抽取流程的必要输入。

## 更新规则

- 只收录交易所或上市公司官网的完整年度报告，不收录摘要、媒体转载或第三方研报。
- 新年度替换前先核对首页、页数和 SHA-256，并同步更新 `manifest.json`。
- PDF 原件不做重压缩、不改页序，确保可追溯性。
