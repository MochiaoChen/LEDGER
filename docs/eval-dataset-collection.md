## 3. 研报（用于选题 5 纠错评测与写作参照）

| 类型 | 数量 | 说明 |
|---|---|---|
| 卖方年报点评 / 深度报告 | 上表中 8～10 家，每家 1～2 篇 | 只作内部评测，不入公开仓库（版权）；入库的只有我们抽出的断言与标签 |
| 优秀深度报告样例 | 5～10 篇，覆盖不同行业和券商 | 用于提炼写作与分析框架（`references/exemplars/`），同样不公开 |

**埋错要求**（每篇 8～15 处，总量 150～200 处）：

- 错误类型分布大致均匀：数值错、单位错（元 / 万元 / 亿元）、期间错配（本期 / 上期、单季 / 累计）、口径错（归母 / 扣非 / 合并 / 母公司）。
- 另放约 20% 的“正确但容易误报”的断言：四舍五入展示、预测值、无真值可核的表述。用来测误报。
- 每处记录：页码、原句、改后句、正确值、错误类型、真值出处（年报页码）。模板可以沿用 `eval/labels.json`。

## 4. 收集分工建议

- 年报 / 季报：巨潮资讯网（深市、北交所）、上交所官网下载，记录下载页链接。
- 卖方研报：各自能合法获取的渠道。注明来源，不外传。
- 埋错与标签：两人一组，一人埋、一人复核标签，避免标签本身出错。
