2. **项目名。** “FinAgent”已经是一篇已发表论文的名字（2024 年的金融交易多模态智能体），论文体例下撞名会被评委注意到。
   建议正式名称另起（例如“衡数”“可溯投研智能体”之类），代码仓库名不变。

## 1. 可行性判断

可以写成论文体例，而且是我们的优势：论文要的是**问题 → 方法 → 实验证据 → 局限**，我们已有的东西都能对上：

| 论文要素 | 我们已有的 | 还缺的 |
|---|---|---|
| 明确的问题 | LLM 写研报会编数字、算错数、凭记忆写外部信息；研报质量难以客观评估 | — |
| 方法贡献 | 确定性计算 + LLM 理解的分工；数字全链路可追溯；双通道抽取；数字护栏 / 数字锁；三 Agent 盲评闭环 | 方法图（架构图、闭环图） |
| 定量实验 | 真实年报抽取（三家 314 个核验值，规则通道 0 错配、覆盖 93%）；研报质检分数 v0 46～49 → v2 88～90；评审校准（稳定性、劣化命中、人工一致） | 扩充评测集后的数字；消融 |
| 可复现 | 全程 trace、文件哈希、golden 快照、135 个测试 | 复现说明页 |
| 局限与合规 | 不构成投资建议、事实 / 推论 / 观点区分、第三方代码声明 | — |

不建议做的：编造“提升 X%”这类没有对照组的数字。每个实验数字都要能在仓库里一条命令复现。

## 2. 结构（正文约 10～12 页 + 附录）

**标题**：《可追溯、可校准的 A 股投研多智能体：从年报到深度研报》（暂定）

**摘要**（约 250 字）：问题、方法三要点、主要结果三个数字、开源与可复现声明。

1. **引言**：大模型做投研的三个失败模式（编数字、算错、外部信息无出处）；评估研报质量缺乏客观标准。
   贡献列四条：
   - 计算与理解分离的架构：LLM 不做算术，每个数字带来源定位；
   - 面向真实年报版式的双通道抽取（稀疏网格、跨页续表、科目折行）与勾稽校验；
   - 生成—复核—盲评三 Agent 闭环，评分标准对生成方不可见，复核改写受数字锁约束；
   - 一套评审模型的校准方法：重复评审稳定性、程序造缺陷的劣化命中、人工一致性。
2. **相关工作**：财报问答与数值推理（FinQA、TAT-QA、FinanceBench 等）；金融智能体；LLM-as-a-judge 与基于评分细则的评测；
   幻觉与可追溯生成。每类两三篇，说明我们的差异。
3. **任务定义**：选题 2、4、5 的输入、输出与评价指标；单位与口径约定。
4. **系统**：
   - 4.1 总体架构（图 1）：解析 → 真值表 → 财报分析 / 估值 / 纠错 → 研报。
   - 4.2 抽取：规则通道与模型通道、证据校验、跨页续表与稀疏列（图 2：真实年报版式示例）。
   - 4.3 分析与估值：三表联动、FCFF 三情景、可比公司；为什么 LLM 不做算术。
   - 4.4 研报纠错：断言抽取、`half_ulp` 容差、错误类型判定，误报控制优先。
   - 4.5 研报生成闭环（图 3）：先搜集后分析、外部来源登记、护栏与数字锁、三 Agent 角色与信息隔离。
5. **评测体系**：四层评分标准（L0 硬闸门 / L1 数据闭合 / L2 分析质量 / L3 表达合规 / 负向条目）与计分；
   评审校准方法。
6. **实验**：
   - 6.1 抽取：真实年报逐值核对（表 1：基线 vs 改进，按公司；覆盖率、错配数）。
   - 6.2 纠错：样例集 + 扩充集的召回 / 精确 / 误报 / 错误类型准确率（表 2）。
   - 6.3 估值一致性：与参照引擎逐项一致（golden 快照）、三表勾稽。
   - 6.4 研报质量：v0 → v2 分数（表 3）、逐层得分；消融：去掉“先搜集”、去掉复核会话、去掉数字锁（如时间允许）。
   - 6.5 评审校准（表 4）：重复评审一致率与总分极差；劣化命中率与连带改判；人工一致的精确率与误报分析。
   - 6.6 成本与耗时：每份研报的 token、时长、费用。
7. **案例研究**：一家公司从年报到研报的完整链路截图，点一个数字回溯到年报页码。
8. **局限、风险与合规**：样例集自造、真实评测集规模有限、评审模型同族偏好、不构成投资建议、数据版权。
9. **结论与后续计划**（决赛前路线图）。

**附录**：A 复现说明（环境、命令、预期输出）；B 评分标准全文；C 劣化算子定义；D 第三方代码声明；E 一份研报样张。

## 3. 排版与工具

- **LaTeX + XeLaTeX**（本机已装）：`ctex` 宏包处理中文，版式取 NeurIPS 风格文件（单栏、Times / 宋体、行距与页边距沿用）。
  论文源码放 `paper/`，图用 matplotlib 与 TikZ，表格用 `booktabs`。
- **图表数字由脚本生成**：`paper/scripts/` 读 `eval/`、`runs/` 的结果写成 `.tex` 表格片段，避免手抄出错；
  正文数字与仓库结果一致是硬要求（可以复用 `numlock` 的思路做一次核对）。
- 参考文献用 BibTeX，只引真实存在、我们读过的文献；不确定的不引。
