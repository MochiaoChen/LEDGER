# FinAgent Web 版使用说明

版本：2026-10-06。源码基线：`46213e4c1560dbbf93bbaee4a75ab08f6b81488b`。本文为当前实现的使用与改动说明；年报端到端试跑尚未执行。

## 1. 入口与状态

公开 Web 界面：https://budangyishujia-bing.github.io/finagent-ui-review/?mode=web

公开 TUI 风格界面：https://budangyishujia-bing.github.io/finagent-ui-review/?mode=tui

两者是同一个前端的两种界面，顶部按钮一键切换，当前任务编号与证据选择共用。公开页面默认显示“样板预览”，其中公司、数字、时间、百分比、证据与文件名来自用户样板，不是新运行结果。预览不启动 Agent，不生成或下载虚构研报。

按用户最新确认，实际后端在本地运行，没有现成服务器。真实任务使用本地 Web 或真正 Terminal，依赖原项目的 Python 环境与已登录的 Claude Code。公开链接用于界面审阅，静态网页不能执行 `claude -p`。

## 2. 安装本次代码

在原项目当前基线的副本中，解压本次代码包，将 `finagent_ui/` 复制到项目根目录，再应用 `integration.patch`：

```bash
git apply --check integration.patch
git apply integration.patch
python -m pip install -e '.[tui,report]'
```

代码包同时提供 `apply.py`，运行 `python /路径/代码包/apply.py --repo /路径/finagent` 可完成复制和补丁应用。脚本先检查补丁和目标文件，遇到版本冲突或已有界面目录会停止，不覆盖用户代码。

要求沿用原仓库：Python 3.12+，Node.js 18+，Claude Code 已安装且已登录，PDF 渲染所需浏览器与中文字体。原项目的模型配置仍由 `FINAGENT_GEN_MODEL` / `FINAGENT_QC_MODEL` 控制。本次没有增加另一套模型 API。

## 3. 启动本地服务

在项目根目录：

```bash
finagent web --state-dir /绝对路径/隔离运行目录
```

或：

```bash
python -m finagent_ui.server --state-dir /绝对路径/隔离运行目录
```

默认服务地址是 `http://127.0.0.1:8765`。本地 Web 是 `/web`，本地深色浏览器界面是 `/tui`。运行目录必须在仓库及仓库上级目录树之外，并避免祖先目录带有 `CLAUDE.md`，这是原编排器的隔离要求。新增界面不会放宽这个要求。

默认运行目录是仓库上上级目录下的 `runtime/`。本地运行建议显式设置持久化目录，避免临时文件失效。关闭服务会停止本服务启动的生产进程组，保留已经落盘的工作区文件。

## 4. 上传年报与开始任务

点击顶部“上传 / 更换年报”或输入文件区域的“更换”。填写：

- 年报 PDF：最大 100 MB；继续沿用原项目不做 OCR 的限制。
- 公司名称与年报年度：明确填写，不从文件名猜测。
- 股价与股价来源：可选；填写股价时来源必填。未填时由原项目研究流程搜集并登记行情。
- 服务地址：本地页面使用本地服务时留空；当前不要求配置公网后端。
- 服务访问凭证：只有服务设置了 `FINAGENT_UI_TOKEN` 才需填写，仅保存在当前浏览器会话，不放入公开源码或链接。
- 勾选确认使用上传来源：上传文件尚未与原项目 `manifest.json` 核验，此确认对应 `allow_unverified`；不自动声称来源已核验。

点击“上传并开始”之后，后端保存输入，调用原 `build()` 搭隔离工作区，随后 `run_agent()` 依次运行五个独立 Claude Code 会话。**这一步会实际调用模型；本次交付过程未执行这一步，须等用户提供年报并下令试跑。**

同一服务同时只启动一个生产任务；已有任务正在运行或暂停时，拒绝启动第二个，避免覆盖工作区。上传更换会建立新的任务编号与工作区，不覆盖已有研究输入或产物。

## 5. 界面各区域

保留样板的横向三区：左侧五个生产角色与阶段，中央当前阶段、输入、Agent / Skill、进度、证据及来源，右侧阶段成果与 PDF / Excel 最终交付。

左侧角色是 Agent，不是 skill。每个 Agent 读取相应 skill 与工作区说明，再调用确定性引擎。界面不会把两者列成平行任务。最新源码的分工如下：

| Agent | 阶段 | 使用的 skill | 主要交付 |
|---|---|---|---|
| 研究助理 | 1 | finagent-report | sources.json、dossier.md、可选 peers.csv |
| 分析师 | 2–7 | finagent-research、finagent-report | 财务事实、分析框架、专题笔记、经营数据、估值假设与计算产物 |
| 主笔 | 8 | finagent-report | narrative.md 与护栏检查 |
| 复核编辑 | 9 | finagent-review | 复核稿、edit_log.md、review.md、数字锁 |
| 排版设计师 | 10–11 | finagent-report / reportkit | 深度研报 PDF、交付说明 |

实际阶段为：资料搜集、财务抽取、分析框架、深度调研、经营数据校验、估值假设、估值运行、形成文稿、复核改写、研报排版、交付说明。调整的是样板区域里的真实阶段文字与归属，保留五角色、十一阶段和区域关系。

中央证据表来自 `facts.json` 或仍然有效的 `facts.verified.json`，显示原值、期间与来源页码。点击行可查看详细来源；点击原文按钮可打开上传年报对应页。当前版本增加原 PDF 页截图接口并内嵌所选来源页，同时保留原 PDF 页码定位；整页截图不伪装成财务表局部裁剪。预览中的表格是样板示意。此截图代码未用年报试跑。

真实模式的百分比是“已通过闸门数 / 11”，不代表当前模型会话的完成百分比。不会生成虚构剩余时间。刷新间隔 3 秒，数据来自原 `status()`；前序阻断与文件过期判断继续由原项目处理。

阶段成果是工作区内部证据。最终交付仅显示真实 PDF 与 Excel，全部闸门通过后才开放下载；界面不把中间 JSON、CSV 当成研报或 Excel。当前未生成新的研究交付物。

## 6. 盲审独立选项

盲审选项放在五角色下方，不是第六个生产角色。勾选只记录当前界面的选择并说明“独立、仅评分、不改原交付物”。本次没有盲审执行接口，没有调用 `evaluation` 或 `refine`。

原仓库的 `refine` 带有评分后问题单路由与返工，与你本次“只增加选项”的要求不同。本次生产入口使用 `run`。将来如需实际盲审，须另行明确接入仅评分的流程。

## 7. 暂停、恢复与下载

运行时“暂停任务”向本服务启动的进程组发送暂停信号，恢复时继续原会话。支持 macOS / Linux；Windows 原生暂不支持进程组暂停，会返回明确提示。

下载按钮读取当前任务真实工作区的已列出文件。路径不在工作区或文件未生成时会拒绝下载。PDF / Excel 打开与下载均不触发新研究。

刷新或切换界面保留浏览器会话中的任务编号。盲审勾选是界面选项，当前未作为后端任务参数；重新载入页面会重置。后端任务记录保存在运行目录，服务重启仍可读取已落盘结果；已结束的进程不会自动重启。原项目 `report run --workspace ...` 的接续能力仍保留，但本次没有新增界面“重试”按钮。

## 8. 本地运行与公开链接的关系

实际任务从 `http://127.0.0.1:8765/web` 或本地 Terminal 启动。公开 Web / TUI 风格链接保留为界面审阅入口；当前没有公网后端，不把公开页面当作已能在线生成研报的服务。HTTPS 公开页面连接本机 HTTP 还可能受浏览器安全策略限制，因此本次使用本地同源页面运行实际任务。后端部署不属于当前要求。

## 9. 本次与原版的差异

新增 HTML Web 与深色浏览器界面、顶部一键切换、共用 HTTP 服务、上传输入、原编排器调用、状态刷新、文件下载与独立盲审选项。新增真正的 Textual 驾驶舱，原 TUI 代码仍可独立调用。

保持原编排器、确定性计算引擎、四个 skill、五会话、十一闸门、隔离边界、护栏、数字锁与模型配置。未改估值公式、研究报告模板、评分标准或角色提示词。没有新增聊天、登录、交易或其他未要求的业务功能。
