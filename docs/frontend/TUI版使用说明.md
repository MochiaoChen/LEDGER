# FinAgent TUI 版使用说明

版本：2026-10-06。本文区分浏览器 TUI 风格界面与真正的 Terminal TUI。年报试跑尚未执行。

## 1. 两个入口

公开 TUI 风格界面：https://budangyishujia-bing.github.io/finagent-ui-review/?mode=tui

这是一份可公开访问的深色浏览器界面，保留样板的左侧 Agent 会话、中间执行流程 / 证据流 / 证据详情、右侧闸门 / 最终交付、顶部输入与底部快捷键布局。顶部“切换 Web”返回白底界面。

真正的终端界面通过 `finagent tui` 或 `python -m finagent_ui.terminal` 启动，运行在 Terminal 中。一个 HTTPS 网页不会自动变成本地终端进程；本次未注册系统协议或启动浏览器外程序。真正终端的 W 键可以打开 Web。

## 2. 安装与启动

按 Web 说明安装本次代码包，在原项目根目录执行：

```bash
python -m pip install -e '.[tui,report]'
finagent web --state-dir /绝对路径/隔离运行目录
```

第二个终端：

```bash
finagent tui --api http://127.0.0.1:8765
```

或：

```bash
python -m finagent_ui.terminal --api http://127.0.0.1:8765
```

两版通过同一个 HTTP 服务共用真实任务状态和工作区，不独立运行第二份研究。按用户最新确认，后端在本地运行，`--api` 使用本机服务地址。若本地服务设置了访问凭证，在终端环境设置 `FINAGENT_UI_TOKEN`，不要把密钥写进命令历史、公开源码或 URL。

建议终端支持 True Color，使用 `TERM=xterm-256color`、`COLORTERM=truecolor`，避免设置 `NO_COLOR`。需要能正确显示中文的等宽字体。建议至少 190 列、55 行；横向三区不转换为纵向卡片，较小终端需要放大窗口。终端渲染依赖实际字体与配色能力。

## 3. 各区域的含义

左侧只有五个生产 Agent：研究助理 → 分析师 → 主笔 → 复核编辑 → 排版设计师。高亮当前角色，显示它调用的 skill；两者是调用关系。盲审选项单独放在五角色下方，当前只记录选择，不执行。

中间上方显示十一阶段与五角色归属。阶段名称与范围来自 2026-10-06 读取的最新源码；横向执行流程保持样板结构。中间证据表显示当前工作区的事实、原值、来源与核验状态，选择行后更新下方来源详情。

右侧读取原闸门的详细结果和下一步；不会根据颜色、闪烁或动画判定通过。最终交付区只显示真实生成并满足闸门的 PDF / Excel。尚未生成时保留等待状态，不提供假文件。

## 4. 快捷键与按钮

| 按键 | 功能 |
|---|---|
| N | 新建年报任务 |
| U | 上传 / 更换年报 |
| R | 刷新真实状态 |
| W | 在浏览器打开当前服务的 Web 界面 |
| P | 暂停 / 继续本服务启动的生产任务，macOS / Linux 支持 |
| O | 打开已经生成的研报 PDF |
| X | 打开已经生成的 Excel |
| Q | 退出当前 TUI，后台服务仍由启动它的终端管理 |

箭头键在证据表中移动选择，详情随行变化。顶部按钮对应上传与 Web 打开。盲审按钮只切换选中状态并提示“不执行、不改交付物”。

浏览器深色界面支持顶部按钮和 N / U / R / W。浏览器与终端的快捷键范围不完全相同，不把浏览器页声称为 Terminal 程序。

## 5. 上传流程

在真正终端按 U 或 N，填写本地年报 PDF 的绝对路径、公司与年度。点击“确认上传并开始”表示确认使用这份尚未在项目清单核验的文件。年报最大 100 MB。

该操作通过 HTTP 上传给同一个服务，后端调用原 `build → run_agent`。终端没有另造模型调用链。**上传并开始会实际调用模型，本次没有进行这一步，等待用户提供年报及试跑指令。**

终端上传表单当前只收年报、公司与年度；可选的股价与来源由 Web 上传表单提供。未填时沿用原项目的资料搜集行为。研究产物通过相同工作区文件交接。

## 6. 动态与光效

浏览器 TUI 使用连续黑蓝背景，移除白色面板缝隙。样板中无文字的侧栏球面纹理、波形、面板纹理直接提取用于同位置装饰，没有改成其他主题。青蓝边缘有移动光点；当前阶段及黄色门控节点有动态脉冲；波形周期变化；完成节点为绿色。

真正终端使用 Textual / Rich 的色彩、边框、高亮与动态字符。每 0.2 秒更新动态波形和当前阶段高亮，每 3 秒读取真实后端状态。Terminal 普通字符单元无法重现浏览器的像素模糊光晕、位图球面和 PDF 截图，因此使用可显示的色彩和动态方式接近样板；这属于用户允许的终端光效限制。

动画是视觉状态提示，不是假执行进度。未连接后端时明确显示连接未建立；没有运行任务时不声称某 Agent 正在执行。浏览器遵守系统“减少动态效果”设置。

## 7. 与原 TUI 的差异

原版是左侧工作区 / 运行目录树与右侧多页标签，包含概览、真值表、估值、质检、追溯、Agent、命令页。新入口按用户样板改为横向驾驶舱，聚焦五角色、十一阶段、证据、门控和 PDF / Excel，并增加运行中定时读取状态和独立盲审选项。

原 `finagent_tui/` 未删除。如需原版功能，可运行：

```bash
python -c 'from finagent_tui.app import main; main()'
```

本次未修改估值计算、旧质检体系和 skill 正文；新增 `finagent_ui/terminal.py`、样式与共用适配层，统一 CLI 的 `tui` 路由指向新驾驶舱。

## 8. 已知使用边界

暂停恢复针对当前服务启动并仍存活的进程组；服务重启不会把旧进程伪装成可控任务。Windows 暂不支持进程组暂停。退出 TUI 只关闭客户端；在启动服务的终端关闭服务才会停止本服务的生产子进程。

真正终端打开本机已有工作区文件；连接远程服务时会转到 Web 入口下载。终端来源详情展示真实来源信息，未在字符终端中内嵌位图 PDF。当前界面没有增加批量任务、任意命令执行或盲审返工按钮。
